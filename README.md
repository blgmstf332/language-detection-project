# Kısa Metinlerde Dil Tespiti (Language Detection)

## Proje Hakkında
Bu proje, Doğal Dil İşleme dersi kapsamında geliştirilmektedir.

Amaç, birkaç kelimeden oluşan kısa metinlerin hangi dilde yazıldığını makine öğrenmesi yöntemleriyle tahmin etmektir.

## Proje Kapsamı
- Türkçe, İngilizce, Almanca ve Fransızca için dil tespiti
- Karakter ve sözcük n-gramlarının karşılaştırılması
- TF-IDF tabanlı metin özelliklerinin kullanılması
- Dil başına F1-score ile performans değerlendirmesi
- Kısa metinlerde hata analizi

## Planlanan Teknolojiler
- Python 3.12
- scikit-learn
- pandas
- Git ve GitHub

## Veri Seti
Mozilla Common Voice veri setinin uygun metin alanlarının kullanılması planlanmaktadır. Veri kaynağı ve kullanım koşulları veri hazırlama aşamasında doğrulanacaktır.
